# *** Draft Copy ***

This is a draft of the forthcoming 1.0 version of the Open Game Data Event Standard.
We encourage you to review this documentation and provide feedback to help shape the final document.

Please provide your comments, complaints, observations, or any other feedback in our [Discussions page](https://github.com/opengamedata/ogd-standards/discussions).

If you would like to begin implementing telemetry logging in your own game with a library that supports the current standard, please use the appropriate client for your game engine below:

* Unity - on [OpenUPM](https://openupm.com/packages/com.fieldday.opengamedata-unity/) - on [GitHub](https://github.com/opengamedata/opengamedata-unity)
* JavaScript - on [GitHub](https://github.com/opengamedata/opengamedata-js-log)
* Godot - on [GitHub](https://github.com/opengamedata/opengamedata-godot)
