# Event Schema Specification v1.0

In order to support interoperation between interactive digital environments (chiefly games), telemetry and data management systems, and data analysis tools, it is important to set common vocabulary and standards. In particular, standards are necessary for defining the structure and content of event data, the most fundamental unit of data in the Open Game Data pipeline.

This document features work towards the specification of an official 1.0 OpenGameData Event Standard. We start with an outline of the elements in the existing, unpublished “0.1” format; discuss additional elements we deem necessary for the 1.0 standard; and finally present the full 1.0 Event Schema and Standard. The Glossary & Appendices clarify terminology used throughout this document, and provide examples of the use of the schema and standard.
