## Other Human Player Action Events (5000–5999)

Other Human Player Action events capture gameplay actions performed by human-controlled actors other than the focal player. These actors are typically other players in multiplayer sessions.

Other Human Player Actions represent intentional actions performed by non-focal human actors, analogous to Player Action events in the 4000 range.

These events mirror the structure of Player Actions but indicate that the acting entity is not the focal player.

| Code Range | Family                   | Family Description |
| ------     | --------------           | ---------------------- |
| 5100–5199  | Puzzle / Constructed Response | Object manipulation actions performed by other actors |
| 5200–5299  | Point-and-Click | Selection and activation actions performed by other actors |
| 5300–5399  | Combat | Combat actions performed by other actors |
| 5400–5499  | Navigation | Movement actions performed by other actors |
| 5500–5599  | Resource Management | Resource acquisition or consumption by other actors |
| 5600–5699  | Simulation | Simulation configuration actions by other actors |
| 5700–5799  | Interface / Structural Navigation | Navigation through game structure by other actors |
| 5800–5999  | Reserved | Reserved for future other actor action families |
